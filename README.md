# Explain QC

Interactive SvelteKit starter for explaining the difference between classical and quantum computers to non-technical learners.

## Stack

- `SvelteKit` + `Svelte 5`
- `Tailwind CSS 4`
- `shadcn-svelte`
- `GSAP` for motion
- `Threlte` + `three` for future Bloch-sphere scenes

## Available now

- A dedicated first page for the “what is a bit?” interaction
- A chapter-based learning shell at `/chapters`
- Unlock progression from one chapter to the next
- Local browser persistence for completion state
- A 3D-ready dependency stack for the Bloch sphere chapter

## Run

```sh
pnpm dev
```

## Validate

```sh
pnpm check
pnpm build
```
